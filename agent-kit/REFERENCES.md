## Corrections and boundaries

- `laya-ultrafast` has local decision inference, but defaults to an OpenRouter text-model call to plan each task. A local text-model endpoint can remove that API expense; browsing websites still requires their network. Its policy combines Laya with deterministic rules, rather than giving Laya sole control over every browser step. See its [README](https://github.com/ipenywis/laya-ultrafast/blob/3581665d1b2e45f6c085a77e59aaeb14a442e65b/README.md) and [policy](https://github.com/ipenywis/laya-ultrafast/blob/3581665d1b2e45f6c085a77e59aaeb14a442e65b/laya_ultrafast/laya.py).
- Arbiter's MCP adapter requires a running HTTP service and MCP Python SDK v2. This kit uses the already tested v1.30 SDK. Its adapter cannot simply be dropped into this environment. See [adapter source](https://github.com/0xBakeer/arbiter/blob/5a178dd964811df4c5d8b2f2984d1cc8021a8bb9/integrations/mcp/arbiter_mcp.py).
- Arbiter's optional Claude `PreToolUse` hook matches `Bash`, defaults to fail-open, and may emit `allow`, bypassing the normal permission prompt. The repository provides `ARBITER_GUARD_NO_AUTO_ALLOW` and `ARBITER_GUARD_FAIL_CLOSED` controls. It is not installed by this kit; it needs a separate decision about permission behavior and evaluation against the actual shell/tool environment. See [hook documentation](https://github.com/0xBakeer/arbiter/blob/5a178dd964811df4c5d8b2f2984d1cc8021a8bb9/docs/integrations.md).
- The playground skill describes upstream direct Python APIs, which accept broader inputs than this kit's intentionally bounded MCP schema. Its statement that an English root checkpoint downloads all sibling models does not match the local Laya 0.3.5 source: `Agent` filters checkpoint files. This kit explicitly downloads selected files at a pinned revision and rejects overlong evidence rather than silently truncating it. See the [reviewed skill](https://github.com/wdobry/laya-playground/blob/5a825ba0472a460830bc937907d43262a87410f8/skills/laya-integration/SKILL.md).
- Published benchmark accuracy, calibration and latency depend on the dataset, checkpoint and hardware. They are not acceptance evidence for this user's SEO or frontend tasks.
